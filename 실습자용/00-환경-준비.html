② 실행 환경 — Python

항목 권장 값 비고
권장 버전 Python 3.11.x 또는 3.12.x 실습에서 가장 안정적으로 검증됨 ✅

확인 방법 python3 --version (mac/Linux) · python --version (Windows) 예: Python 3.12.7

설치 방법 (OS별):

  • Windows: python.org/downloads → Python 3.12.x 설치파일(.exe) 다운 → 실행 화면 맨 아래 ☑ Add python.exe to PATH 체크 → Install Now. 확인: python --version.
  • macOS (둘 중 택 1):
  • 공식 설치파일: python.org/downloads/macos → Python 3.12.x macOS 64-bit universal2 installer 다운 → 실행.
  • Homebrew: brew install python@3.12 (먼저 brew.sh 설치). 확인: python3.12 --version.
  • Linux (Ubuntu/Debian): sudo apt update && sudo apt install python3.12 python3.12-venv python3-pip

bash git clone https://github.com/SAP-samples/generative-ai-codejam.git 3. codejam.code-workspace 열기

2. Python 환경 & SDK

python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
  • python3 -m venv .venv : 이 프로젝트 전용 가상환경을 만듭니다 (다른 프로젝트와 라이브러리가 섞이지 않게).
  • source .venv/bin/activate : 방금 만든 가상환경을 켭니다. 프롬프트 앞에 (.venv) 가 보이면 성공.
  • pip install -r requirements.txt : 실습에 필요한 SDK(generative-ai-hub-sdk 등)를 한 번에 설치합니다.

ℹ️ 노트북을 실행할 때는 오른쪽 위 커널(Kernel) 선택에서 이 .venv 를 골라야 합니다. 커널이 잘못되면 "ModuleNotFoundError" 가 납니다. → 자세한 해결은 99-트러블슈팅-FAQ.

3. 연결 값 입력 — variables.py

강사가 공유한 값을 exercises/variables.py 에 넣습니다. 대부분 공유 값이고, 테이블명만 본인 고유값입니다.

변수 값 비고
RESOURCE_GROUP 강사 공유 공유 리소스 그룹
LLM_DEPLOYMENT_ID 강사 공유 공유 배포
EMBEDDING_DEPLOYMENT_ID 강사 공유 공유 배포
AICORE_ORCHESTRATION_DEPLOYMENT_URL 강사 공유 공유 배포
GROUNDING_REPOSITORY_ID 강사 공유 내 문서 그라운딩 저장소(모듈 5)

AI Core 자격증명은 강사가 준 ~/.aicore/config.json 또는 환경변수로 설정합니다. init_env.set_environment_variables() 가 variables.py 값을 환경변수로 세팅합니다.

ℹ️ 모든 값이 공유 값입니다. 그라운딩 저장소도 강사가 미리 문서를 수집해 둔 공유 저장소를 읽기만 합니다(모듈 5).

4. 연결 확인

exercises/03-prompt-llm.ipynb 의 첫 셀을 실행합니다. 이 셀은 AI Core를 아직 호출하지 않고, 입력한 연결 값이 코드에서 제대로 읽히는지만 확인합니다.

import init_env
import variables
import importlib
init_env = importlib.reload(init_env)        # variables.py 를 방금 수정했으면 reload 로 다시 읽음
variables = importlib.reload(variables)

init_env.set_environment_variables()         # variables.py 값을 환경변수로 세팅 (SDK가 여기서 읽음)

print(f"Resource group: {variables.RESOURCE_GROUP}")
print(f"Embedding deployment ID: {variables.EMBEDDING_DEPLOYMENT_ID}")
print(f"LLM deployment ID: {variables.LLM_DEPLOYMENT_ID}")
print(f"Orchestration URL: {variables.AICORE_ORCHESTRATION_DEPLOYMENT_URL}")

한 줄씩 무슨 일이 일어나나요?

코드 하는 일
import variables 내가 값을 적어둔 variables.py 를 불러옴
importlib.reload(...) 값을 방금 바꿨을 때 노트북이 옛 값을 기억하지 않도록 다시 읽음
init_env.set_environment_variables() variables.py 의 값을 환경변수로 올려, SDK가 자동으로 집어감
print(...) 값이 제대로 들어왔는지 눈으로 확인

💡 None 이 출력되면 해당 값이 variables.py 에 비어 있다는 뜻입니다. 값을 채우고 셀을 다시 실행하세요 (reload 덕분에 재시작 없이 반영됩니다).

5. (선택) 코드로 환경 확인 — inspect_aicore.py

Launchpad UI 대신 터미널에서 바로 내 환경을 확인할 수 있습니다.

python inspect_aicore.py                 # 배포 + 그라운딩 저장소 요약
python inspect_aicore.py deployments     # orchestration/모델이 RUNNING인지, URL 확인
python inspect_aicore.py collections     # 내 그라운딩 저장소 목록(+문서 수)

출력 예:

[배포] ...
  orchestration   RUNNING
       URL=.../v2/inference/deployments/xxxx    ← variables.py 의 Orchestration URL
  foundation-models RUNNING model=gpt-5.6-sol
[그라운딩 저장소]
  title=...  docs=4  id=xxxx                    ← 모듈 5 GROUNDING_REPOSITORY_ID

UI 없이 "내 orchestration 배포 URL / 모델명 / 저장소 id" 를 코드로 확인하는 용도입니다.

✅ 체크포인트

  • 위 셀이 에러 없이 값을 출력한다 (None 아님)
  • GROUNDING_REPOSITORY_ID 등 강사 공유 값을 모두 입력했다
  • (선택) python inspect_aicore.py 로 배포·저장소가 보인다

🆘 잘 안 될 때 (자주 겪는 3가지)

증상 원인 해결
ModuleNotFoundError 커널이 .venv 가 아님 / 설치 안 됨 노트북 커널을 .venv 로 선택, pip install -r requirements.txt 재실행
값이 None 으로 출력 variables.py 에 값 미입력 강사 공유 값을 넣고 셀 재실행 (reload로 반영됨)
인증/401 에러 AI Core 자격증명 미설정 ~/.aicore/config.json 또는 환경변수 확인

출력이 비거나 에러면 위 표를 먼저 확인하고, 그래도 안 되면 강사에게 알리세요 (대부분 연결 값 미입력).
