# 모듈 7 · 마무리 & 보너스 활동

🎯 **목표**: 배운 것을 실무로 연결하고, 더 해볼 거리를 안다.
⏱️ **시간**: 마무리 10분 + 보너스(여유분)

---

## 오늘 배운 것

```
LLM 호출(1) → 임베딩(2) → Orchestration+필터(3) → 공개 그라운딩(4) → 내 문서 그라운딩(5) → 메모리 챗봇(6)
```

| 모듈 | 한 줄 요약 | 기억할 코드 포인트 |
| --- | --- | --- |
| 1 | 모델 호출 + role + 환각 | `chat.completions.create(model_name=...)` |
| 2 | 텍스트 → 벡터, 의미 유사도 | `embeddings.create(...)`, 코사인 유사도 |
| 3 | 템플릿·필터·마스킹 조립 | `OrchestrationConfig(modules=ModuleConfig(...))` |
| 4 | 공개 문서로 근거 답변 | `DocumentGroundingFilter(data_repository_type="help.sap.com")` |
| 5 | 내 문서로 소스 교체 | `data_repository_type="vector", data_repositories=[id]` |
| 6 | 대화 기억 | `run(..., history=self.history)` |

- 모델명 한 줄 교체로 GPT ↔ Claude ↔ Gemini 전환 (Gen AI Hub 핵심 가치)
- 그라운딩은 **소스만 바꾸면**(필터 한 줄) 공개(help.sap.com) ↔ 내 문서(vector) 전환
- Orchestration = 템플릿·필터·그라운딩·마스킹을 선언형으로 조합
- 환각(모듈 1)을 그라운딩(모듈 4·5)으로 **실제로 줄이는** 흐름을 체험

## 실무 연결 아이디어

- **규정 준수형 지식봇**: 그라운딩(내 문서) + 콘텐츠 필터 + 데이터 마스킹 결합
- **다국어 고객지원**: 그라운딩 + Translation 모듈
- **문서 자동 처리**: 멀티모달(이미지/PDF) + 구조화 추출(JSON)

---

## 보너스 활동 (난이도 순)

### 1. 콘텐츠 필터 + 그라운딩 합치기 · ★☆☆

모듈 3의 `filtering` 과 모듈 4의 `grounding` 을 하나의 `ModuleConfig` 에 함께 넣어 "근거 기반 + 안전 필터" 파이프라인 완성.

### 2. 그라운딩 심화 — 여러 소스·메타데이터 필터 · ★★☆

- `filters` 리스트에 **공개(help.sap.com) + 내 저장소(vector)** 를 함께 넣어 복수 소스 검색
- `data_repository_metadata` / 문서·청크 메타데이터로 검색 범위 좁히기
- (심화) 수집을 코드로: AI Core **Document Grounding REST API** 로 저장소 생성·문서 업로드 (SAP Help의 Grounding API 문서 기준)

### 3. 메모리 + 그라운딩 챗봇 · ★★☆

모듈 6의 ChatBot `config` 에 모듈 4의 grounding을 넣어 "기억하는 지식봇".

### 4. AI 에이전트 · ★★★

LiteLLM + CrewAI 등으로 도구를 쓰는 에이전트로 확장. (저장소 README의 옵션 링크 참고)

## 💡 Vibe coding 보너스 팁

스스로 Copilot으로 코드를 짜볼 때, `exercises/documents/` 의 SDK 레퍼런스 PDF를 **컨텍스트로 물려주세요**:

- `GenerativeAIhubSDK_...pdf`
- `Orchestration_Service_...pdf`
- `DocumentGrounding_...pdf`

`gen_ai_hub.orchestration_v2` 는 니치한 SDK라, 그냥 시키면 Copilot이 API를 **환각**합니다 (`orchestration` vs `orchestration_v2`, 클래스명 등). **문서를 먼저 먹이고 → 프롬프트하고 → 노트북 코드를 정답지 삼아 검증**하는 게 핵심입니다.
