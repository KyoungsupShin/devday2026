## 🔧 환경 셋업에서 막힌 점 (실습생이 실제로 겪음)

1. **시스템 Python이 externally-managed** → `pip install` 직접 실행 시 거부(PEP 668).
   - 해결: `python3 -m venv .venv` 전용 가상환경 생성 후 설치. (교재 모듈 0과 동일 흐름이라 OK)
2. **로컬 Python이 3.14** → 교재/검증 리포트는 3.13. SDK(`sap-ai-sdk-gen==5.11.0`)·scipy 설치/임포트는 3.14에서도 문제 없었음.
3. **자격증명 형식 차이**: 받은 건 BTP service key(JSON). config.py가 읽는 env 로 매핑 필요.
   - `url`→`AICORE_AUTH_URL`, `serviceurls.AI_API_URL`→`AICORE_BASE_URL`, `clientid`→`AICORE_CLIENT_ID`, `clientsecret`→`AICORE_CLIENT_SECRET`.
   - → 교재 모듈 0 "연결 값 입력" 표에 **service key JSON → env 매핑 표**를 추가하면 참가자 혼선 감소.
4. **client secret 에 `=`,`$` 포함** → `.env` 파싱 시 `split("=",1)` 로 안전 처리 필요(그냥 `split("=")` 쓰면 깨짐). `_env.py` 에 반영.

## 👀 실습생 관점 발견 (교재 보강 후보)

- **Step 2 유사도 대비가 약함**: `apple-orange(0.471)` vs `apple-phone(0.466)` 차이가 **0.005**로 거의 없음.
  검증 리포트의 "apple~orange 0.471 > apple~physics 0.127"처럼 **대비가 큰 단어쌍(physics 등)**을 교재 기본 예시로 쓰면
  "유사도가 의미를 반영한다"는 포인트가 훨씬 선명해짐. (phone 은 임베딩상 과일과 꽤 가깝게 나옴)
- **Step 1 vs Step 4 환각 비교가 아주 좋음**: 같은 질문에서
  - 그라운딩 전: "token/redacted/reinsert" 같은 **일반론(지어냄)**
  - 그라운딩 후: "**AI Launchpad에서 Data Masking 모듈 활성화**" 같은 **제품 실제 절차**
  → 교재에 이 before/after 문장을 **예시 캡션**으로 박아두면 효과 큼.
- **마스킹 데모 팁**: 번역 템플릿으론 마스킹 효과가 가려짐. "입력을 그대로 반복" 템플릿을 쓰면
  `MASKED_PERSON`/`MASKED_EMAIL` 치환이 출력에 바로 보여 교육 효과가 큼. (step03 에 반영)
- **Step 5 저장소 자동선택**: 참가자가 id 를 안 받아도 "문서 있는 첫 저장소"로 폴백하면 데모가 끊기지 않음.
  단, 공유 테넌트엔 `test-collection`(docs=0) 처럼 빈 저장소도 있으니 **docs>0 필터** 필수.
