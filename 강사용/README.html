SAP Generative AI Hub 핸즈온 — 4시간 (강사용 가이드)

이 폴더는 강사용입니다. 실습자용 내용에 더해 각 모듈마다 왜 이 개념인지, 뭐라고 설명할지, 예상 질문, 흔한 실수, 데모 포인트, 전환 멘트, 시간 배분을 자세히 담았습니다.

기반 자료: SAP-samples/generative-ai-codejam (노트북 02~11) 실습자용 폴더: ../실습자용/

이 과정의 운영 전제 (중요)

  • 단일 공유 AI Core: AI Core 인스턴스는 하나만 구성해 전원이 공유합니다. 배포(Orchestration·LLM·임베딩)는 강사가 미리 1회 만들어 두고, 연결 값만 참가자에게 공유합니다. → 참가자별 배포가 없으므로 설정 시간이 대폭 단축됩니다(모듈 0이 15분).
  • SDK 중심: 참가자는 주로 노트북에서 SDK 코드를 작성·실행합니다. Launchpad UI 실습(NB 01 프롬프트 에디터, NB 07 S3 그라운딩)은 강사 데모 또는 보너스로만 다룹니다.
  • 절약된 설정 시간은 SDK 실습·실험에 재투자하세요.

🧑‍🏫 공유 AI Core 구성 (강사가 1회 사전 설정)

핸즈온 전에 한 번만 해두면 됩니다.

  1. AI Core 인스턴스 1개 + 공유 리소스 그룹 1개(예: codejam). 참가자별 리소스 그룹은 SDK 경로에선 불필요.
  2. 배포 3종을 그 리소스 그룹에 생성하고 RUNNING 확인: - Orchestration 배포 → 배포 URL 확보 - LLM 프록시 (예: gpt-5.6-sol) → deployment ID - 임베딩 프록시 (text-embedding-3-small) → deployment ID
  3. 공유 벡터 저장소 1개(모듈 5용) — Grounding Management(UI) 또는 REST로 생성하고 documents/ PDF를 수집(ingest), Run Search로 검색 확인 → 저장소 id 확보. (수집은 SDK 일급 기능이 아니므로 강사가 사전 처리)
  4. 참가자에게 공유할 값 배포: - RESOURCE_GROUP, LLM_DEPLOYMENT_ID, EMBEDDING_DEPLOYMENT_ID, AICORE_ORCHESTRATION_DEPLOYMENT_URL, GROUNDING_REPOSITORY_ID - AI Core 자격증명(~/.aicore/config.json 또는 환경변수용 client id/secret/auth url/base url) - 배포된 모델명 목록

⚠️ 공유 인스턴스에서 반드시 챙길 것

위험 이유 조치
동시 호출 지연·제한 공유 배포에 요청 폭주 실험을 시차로, 실패 시 재시도 안내
그라운딩 저장소 참가자는 읽기(질의)만, 수집은 강사 공유 저장소 1개를 전원이 읽기 → 안전
공용 리소스 변경 공유 documents/ 등 삭제·수정 금지 공지

참가자는 모두 공유 배포·공유 그라운딩 저장소를 읽기만 합니다(쓰기 없음). 그래서 참가자별 리소스를 만들 필요가 없어 공유 인스턴스 + SDK 경로에 가장 잘 맞습니다.

이 핸즈온의 목표 (강사가 머릿속에 둘 것)

  1. "모델을 바꿔도 코드가 그대로다" — Gen AI Hub의 모델 harmonize. 모듈 1·3·4에서 name/model_name 한 줄 교체를 반복 체험.
  2. "RAG는 선언형 모듈 조합으로 된다" — Orchestration Grounding으로 관리형 RAG. 소스는 공개(모듈 4)든 내 문서(모듈 5)든 필터 한 줄 차이.

전체 흐름의 서사(narrative)

모듈 1: LLM은 똑똑하지만 "모르는 것"을 지어낸다 (환각 시연)
   ↓  그럼 어떻게 근거를 줄까?
모듈 2: 텍스트를 숫자(임베딩)로 → 의미 유사도를 계산
   ↓  이 유사도로 관련 문서를 찾아 넣으면 RAG
모듈 3: 여러 모듈을 파이프라인으로 (템플릿+필터) = Orchestration
   ↓  여기에 "근거 검색" 모듈을 추가하면?
모듈 4: Document Grounding = 관리형 RAG, 공개 소스(help.sap.com)
   ↓  그럼 우리 문서는? 소스만 바꾸면 된다
모듈 5: 같은 그라운딩을 내 문서(AI Core 벡터 저장소)로 — 필터 한 줄
   ↓  대화가 이어지려면 기억이 필요
모듈 6: 메모리 챗봇

모듈 1의 환각 질문을 모듈 4에서 그대로 다시 던져 수미상관을 완성하세요.

1:20–2:05 3. Orchestration+필터+마스킹 config 조립·입출력 필터·PII 마스킹 개념 밀도 높음
2:05–2:15 ☕ 휴식
