## 🧑‍🏫 마무리 진행법

💬 **핵심 마무리 질문**: "그라운딩이 있을 때와 없을 때 답이 어떻게 달랐나요?" — 모듈 4에서 본 before/after를 다시 상기시켜 RAG의 가치를 각인.

## 실무 연결 (청중 맞춤)

SKT/고객 맥락으로 구체화:

- **규정 준수형 사내 지식봇**: 사내 문서 그라운딩 + 콘텐츠 필터 + 데이터 마스킹
- **다국어 고객지원**: 그라운딩 + Translation 모듈
- **문서 자동화**: 멀티모달로 스캔/PDF → 구조화 JSON
