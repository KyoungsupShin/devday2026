모듈 7 · 마무리 & 보너스 활동 (강사용)

🎯 목표: 서사를 닫고, 실무 연결 + 시간 남을 때의 추가 활동 운영. ⏱️ 시간: 마무리 10분 + 보너스(남는 시간 전부) 📓 기반: 노트북 07(S3 그라운딩 UI), 11(자유 챗봇), README의 에이전트 옵션 링크

🧑‍🏫 마무리 진행법

오늘의 서사를 참가자 입으로 요약하게 하세요. 강사가 정리하지 말고 질문으로 끌어내기:

  • "모듈 1에서 뭐가 문제였죠?" (환각)
  • "그걸 뭘로 풀었죠?" (그라운딩 / RAG)
  • "모델을 Claude로 바꾸려면 뭘 고쳤죠?" (이름 한 줄)

💬 핵심 마무리 질문: "그라운딩이 있을 때와 없을 때 답이 어떻게 달랐나요?" — 모듈 4에서 본 before/after를 다시 상기시켜 RAG의 가치를 각인.

실무 연결 (청중 맞춤)

SKT/고객 맥락으로 구체화:

  • 규정 준수형 사내 지식봇: 사내 문서 그라운딩 + 콘텐츠 필터 + 데이터 마스킹
  • 다국어 고객지원: 그라운딩 + Translation 모듈
  • 문서 자동화: 멀티모달로 스캔/PDF → 구조화 JSON

보너스 활동 운영 (시간이 남으면)

남는 시간/청중 관심에 따라 고르세요. 모두 오늘 배운 블록의 재조합입니다.

# 활동 난이도 포인트
1 필터 + 그라운딩 합치기 ★☆☆ 모듈 조합 체감
2 복수 소스 그라운딩 (공개 + 내 문서) ★★☆ 필터 리스트에 둘 다
3 메모리 + 그라운딩 챗봇 ★★☆ 종합
4 REST로 문서 수집 자동화 ★★★ Grounding API 심화
5 AI 에이전트 (LiteLLM/CrewAI) ★★★ 확장 주제

🧑‍🏫 수집(ingestion) 과정을 더 보고 싶어하면 Grounding Management(UI) 절차나 관련 영상("AI Foundation — Orchestration workflow with grounding using S3")을 보여주세요. 참가자가 코드로 수집하고 싶어하면 보너스 4(REST).

🧑‍🏫 보너스 3 은 가장 만족도 높은 종합 과제입니다 — 오늘 만든 조각(그라운딩 config + ChatBot)을 합치면 끝. 시간 되면 이걸 우선.

💡 Vibe coding 안내 (참가자가 스스로 짤 때)

documents/ 의 SDK PDF 3종을 Copilot 컨텍스트로 물리게 하세요. orchestration_v2 가 니치해서 그냥 시키면 환각합니다. "문서 먹이고 → 프롬프트 → 노트북으로 검증" 3단계를 강조. 모듈 2의 "의도된 버그"에서 심은 '출력을 비판적으로 보라'는 태도와 연결하면 메시지가 일관됩니다.

🎬 마무리 체크 (참가자가 가져가는 것)

  • 모델 교체가 한 줄임을 체감했다
  • 그라운딩 on/off 차이를 직접 봤다
  • Orchestration 모듈 조합을 이해했다
  • 각자 실무 적용 아이디어를 하나씩 말했다
