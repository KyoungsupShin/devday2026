모듈 0 · 연결 확인 (강사용)

🎯 목표: 전원이 공유 AI Core에 연결된 상태로 출발. ⏱️ 시간: 15분 (사전 배포 완료 전제 — 참가자는 값만 입력)

배포는 강사가 1회 완료(README의 "공유 AI Core 구성" 참고). 당일 참가자는 연결 값 입력 + 확인만 합니다.

🧑‍🏫 강사 노트 — 공유 인스턴스라 짧다

참가자별 배포가 없으므로 모듈 0이 매우 짧습니다. 핵심은 연결 값을 정확히 배포하고, 연결 확인 셀 초록불을 전원이 보게 하는 것. pip install 이 도는 2~4분 동안 모듈 1의 개념(토큰·LLM이란?)을 먼저 이야기하면 빈 시간이 메워집니다.

💬 먼저 이렇게 공지하세요: "오늘은 AI Core 하나를 다 같이 씁니다. 배포와 그라운딩 저장소까지 제가 다 해뒀으니, 여러분은 공유 값만 넣고 읽기(질의)만 하면 됩니다 — 서로 간섭할 일이 없어요."

진행 순서

1. clone & venv & install

git clone https://github.com/SAP-samples/generative-ai-codejam.git
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

🧑‍🏫 패키지명은 sap-ai-sdk-* 로 보일 수 있으나 import는 gen_ai_hub.*. Firefox 이슈 → Chrome/Edge.

2. variables.py — 공유 값 배포

🎬 가능하면 공유 값이 미리 채워진 variables.py 템플릿을 나눠주세요. 그러면 참가자는 그대로 쓰면 끝(전부 공유 값).

변수 출처 비고
RESOURCE_GROUP 공유 공유 리소스 그룹명
LLM_DEPLOYMENT_ID 공유
EMBEDDING_DEPLOYMENT_ID 공유
AICORE_ORCHESTRATION_DEPLOYMENT_URL 공유
GROUNDING_REPOSITORY_ID 공유 내 문서 그라운딩 저장소(모듈 5)

⚠️ 자격증명(config.json/환경변수)도 공유해야 합니다. 민감정보이므로 안전한 경로(사내 공유, 세션 중 화면)로 전달하고, 세션 후 폐기 정책을 정하세요.

3. 연결 확인 셀

🎬 강사 화면에서 먼저 돌려 "이렇게 나오면 성공"을 보이고, 참가자가 각자 실행.

❓ 예상 질문

  • "리소스 그룹이 왜 다 같아요?" → 공유 인스턴스라 하나를 같이 씀. SDK로 배포·그라운딩 저장소를 '소비(읽기)'만 하므로 공유해도 안전.
  • "내 호출이 남한테 보이나요?" → 호출 자체는 격리됩니다. 공유 저장소는 읽기 전용이라 서로 영향 없음.
  • "자격증명을 왜 공유해요?" → 이 핸즈온 한정. 실무에선 참가자별 서비스 키/권한 분리 권장이라고 덧붙이세요.

⚠️ 흔한 실수

증상 원인 조치
ID/URL None variables.py 미입력 값 채우고 커널 재시작
401/403 자격증명 미설정 config.json/환경변수 확인
그라운딩 빈 답(모듈 5) GROUNDING_REPOSITORY_ID 미입력 공유 저장소 id 확인
반영 안 됨 캐시 importlib.reload 또는 커널 재시작
