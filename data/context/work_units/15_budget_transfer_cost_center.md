# 예산 이관 또는 Cost Center 변경 검토

## 목적

비용 귀속, 예산 이관 또는 Cost Center 변경이 필요할 때 재무 통제와 사업성 관점을 분리해 필요한 근거를 정리한다.

## 적용 범위

예산 이관, Cost Center 변경 또는 비용 귀속 변경의 검토에 적용한다. 예산 배정·승인, 회계 처리와 ERP 반영은 별도 절차에 따른다.

## Stakeholder

| 역할 | 책임 |
| --- | --- |
| 재무팀 | 예산, 비용 귀속, 원가와 관리회계 관점의 근거를 검토한다. |
| 사업기획팀 | 사업성, 수익성, 계획 가정과 운영 영향의 근거를 검토한다. |
| IT팀 | 승인된 변경이 ERP·MDM 데이터에 미치는 영향을 별도로 검토한다. |
| 권한 있는 사람 | 공식 승인·배정·변경 결정을 내린다. |

## 프로세스

1. 요청 부서는 변경 대상 Cost Center, 적용 기간, 변경 사유와 요청 목적을 재무팀에 전달한다.
2. 재무팀은 예산·원가·비용 귀속·이관 근거와 한계를 검토한다.
3. 사업기획팀은 재무팀 검토 근거를 바탕으로 사업성·계획 영향과 불확실성을 별도 관점에서 검토한다.
4. 권한 있는 사람의 승인 대상이 되는 변경으로 데이터 영향이 확인된 경우에만 IT팀에 관련 근거를 인계해 ERP·MDM 변경 통제를 검토한다.
5. 재무·사업기획·필요 시 IT 검토 근거와 미확정 항목을 누적해 권한 있는 사람에게 공식 결정으로 전달한다.

## 단계별 인계 기준

1. **요청 부서 → 재무팀:** 변경 대상 Cost Center·기간·비용·예산 근거, 변경 사유와 현재 승인 상태를 전달한다.
2. **재무팀 → 사업기획팀:** 비용 귀속·예산·원가 관점의 검토 결과와 한계를 전달해 사업성·계획 영향 검토를 분리한다.
3. **승인 대상 변경 → IT팀:** 권한 있는 사람의 결정 대상이고 ERP·MDM 데이터 영향이 확인된 경우에만 변경 근거·대상 식별자·승인 상태를 전달한다.
4. **재무·사업기획·IT → 권한 있는 사람:** 검토 결과와 미확정 항목을 누적하되, 예산 이관·회계 처리·ERP 반영은 별도 공식 결정 및 실행으로 구분한다.

## 확인 사항과 산출물

- 확인 사항: 변경 대상, 기간, Cost Center, 비용·예산 근거, 사업성 영향, 승인 상태
- 산출물: 재무·사업성 검토 기록, 최종 확인 입력

## 실행 경계

검토 완료는 예산 이관, Cost Center 변경, 회계 전기 또는 ERP 변경 완료를 뜻하지 않는다.
