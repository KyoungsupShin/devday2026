# 안전·환경 사고 또는 위험 신고

## 목적

사고, 아차사고, 환경·화학물질 위험이 보고되었을 때 현장 사실과 즉시 조치, 후속 확인을 구분해 관리한다.

## 적용 범위

안전·환경 사고, 아차사고 및 위험 신고에 적용한다. 법적 신고, 작업 중지, 허가 발급과 사고 원인 확정은 별도 권한·규정에 따른다.

## Stakeholder

| 역할 | 책임 |
| --- | --- |
| 현장 작업자 | 현장 사실, 시점, 대상과 즉시 조치를 기록하고 공유한다. |
| EHS | 위험·환경 영향, 증빙과 후속 확인 항목을 검토한다. |
| 설비·생산·품질팀 | 영향이 있는 경우 각 전문 범위의 사실과 근거를 제공한다. |

## 프로세스

1. 사고·위험 사실, 대상, 시점, 위치와 즉시 조치를 기록한다.
2. EHS는 제공된 기록을 바탕으로 안전·환경 확인 범위와 필요한 증빙을 검토한다.
3. 설비·생산·품질 영향이 있으면 각 부서에 사실과 확인 질문을 인계한다.
4. 조치, 담당자, 확인 기한과 미확정 항목을 추적한다.
5. 공식 신고·승인·작업 허가가 필요한 경우 권한 있는 절차로 인계한다.

## 단계별 인계 기준

1. **현장 작업자 → EHS:** 사고·아차사고·위험의 위치·시각·대상, 관찰 사실, 관련 인원·설비·물질, 즉시 조치와 확보된 증빙을 전달한다.
2. **EHS → 설비·생산·품질팀:** 영향이 확인된 전문 영역에만 위험 설명·영향 범위·보존해야 할 기록·확인 질문을 전달한다. 원인 확정 전에는 가설을 사실로 기록하지 않는다.
3. **EHS → 권한 있는 절차:** 법적 신고, 작업 중지·재개, 허가, 공식 시정조치가 필요한 경우에만 누적 사실·증빙·미확정 항목을 권한자에게 인계한다.

## 확인 사항과 산출물

- 확인 사항: 대상·위치, 시점, 사실, 즉시 조치, 안전·환경 영향, 증빙, 후속 기한
- 산출물: 안전·환경 이슈 기록, 조치 추적 목록

## 실행 경계

위험 신고와 검토는 법적 신고, 작업 허가, 사고 원인 확정 또는 공식 승인 자체를 수행하지 않는다.
