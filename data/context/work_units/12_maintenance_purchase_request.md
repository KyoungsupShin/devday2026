# 설비 부품·유지보수 구매 요청

## 목적

설비·부품·유지보수 구매 필요에 대한 기술, 수급과 생산 영향 근거를 누적해 최종 검토에 필요한 입력을 만든다.

## 적용 범위

부품 교체, 보수 또는 유지보수 구매 요청에 적용한다. 공급처 확정, 구매 발주, 예산 배정과 승인·시스템 반영은 포함하지 않는다.

## Stakeholder

| 역할 | 책임 |
| --- | --- |
| 설비팀 | 기술 필요성, 대상 식별, 운전·안전 영향, 제약과 사양을 검토한다. |
| 구매팀 | 기준정보, 재고·수급, 공급 조건과 구매 요청 상태를 검토한다. |
| 제조기획팀 | 생산계획, 투입 준비도, 라인·운영 영향을 검토한다. |
| 권한 있는 사람 | 누적 근거를 바탕으로 공식 결정이 필요할 때 최종 판단을 한다. |

## 프로세스

1. 현장 사실, 대상 식별과 기술 필요를 설비팀에 전달한다.
2. 설비팀은 기술 관찰, 사양, 운전·안전 영향과 미확정 기술 입력을 기록한다.
3. 구매팀은 설비팀 근거를 바탕으로 기준정보, 재고·수급, 공급 조건과 요청 상태를 검토한다.
4. 제조기획팀은 구매팀 근거를 바탕으로 생산계획, 투입 준비도와 운영 영향을 검토한다.
5. 세 부서의 근거와 미확정 항목을 누적해 요청 부서에 전달하고, 필요 시 최종 확인으로 인계한다.

## 단계별 인계 기준

1. **현장 또는 요청 부서 → 설비팀:** 설비·부품 식별자, 고장·소모 사실, 필요 시점, 현장·안전 영향과 기존 조치·근거를 전달한다.
2. **설비팀 → 구매팀:** 기술 필요성·사양·호환성·대체 가능성·운전 제약과 기술적으로 확인되지 않은 항목을 전달한다.
3. **구매팀 → 제조기획팀:** 기준정보, 재고·예약·입고·공급 조건, 예상 부족·지연과 구매 상태를 전달해 생산계획 영향을 검토하게 한다.
4. **제조기획팀 → 권한 있는 사람:** 생산·라인 영향 및 필요 시점을 포함한 누적 근거를 전달한다. 승인·예산 배정·발주·시스템 반영은 이 인계 이후 별도 절차다.

## 확인 사항과 산출물

- 확인 사항: 대상·사양, 기술 제약, 재고·수급, 공급 조건, 생산 영향, 미확정 항목
- 산출물: 부서별 검토 기록, 누적 인계서, 최종 확인 요청

## 실행 경계

검토 순서는 근거 축적 기준이며 구매 승인, 공급처 확정, 예산 배정 또는 발주를 뜻하지 않는다.
