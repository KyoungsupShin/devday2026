# 품질 시험·검사 현황 검토

## 목적

시험·검사·규격 적합성 기록의 상태를 확인하고 결과와 미확정 항목을 관련 부서에 명확히 전달한다.

## 적용 범위

일일 또는 배치별 시험·검사 현황 검토에 적용한다. 품질 release, 출하 승인과 제품 처분 결정은 별도 절차에 따른다.

## Stakeholder

| 역할 | 책임 |
| --- | --- |
| 품질팀 | 대상, 규격, 시험·검사 기록과 확인 필요 사항을 검토한다. |
| 생산팀 | 배치·라인·생산 기록과 운영 사실을 제공한다. |
| R&D·공정팀 | 규격 또는 공정 관련 추가 검토가 필요한 경우 각 전문 근거를 제공한다. |

## 프로세스

1. 시험·검사 대상, 배치 또는 기간과 적용 규격을 확인한다.
2. 시험·검사 기록의 시점, 결과와 누락 여부를 검토한다.
3. 확인된 결과와 미확정 항목을 분리한다.
4. 생산·R&D·공정 관련 확인이 필요하면 해당 근거와 질문을 인계한다.
5. 공식 판정이 필요한 상태를 별도로 기록한다.

## 단계별 인계 기준

1. **생산팀 → 품질팀:** 배치·제품·라인 식별자, 생산 시점·공정 기록, 시료·시험 요청 정보와 관찰된 운영 이슈를 전달한다.
2. **품질팀 → R&D·공정팀:** 규격 해석, 시험 방법, 배합 또는 공정 조건의 전문 확인이 필요한 경우에만 시험 결과·규격·편차·확인 질문을 인계한다.
3. **품질팀 → 권한 있는 사람:** 데이터와 전문 검토가 누적된 뒤 release·처분·출하 승인 등 공식 판정이 필요하면 그 상태와 미확정 항목을 구분해 전달한다.

## 확인 사항과 산출물

- 확인 사항: 대상 식별, 규격, 시험 기록, 결과, 누락, 관련 부서 질문
- 산출물: 품질 검토 기록, 확인 요청

## 실행 경계

기록 검토는 품질 승인, 출하 승인 또는 규격 적합성의 최종 판정을 대신하지 않는다.
