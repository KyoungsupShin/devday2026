# 설비 이상 또는 고장 검토

## 목적

설비 이상, 성능 저하 또는 안전·운전 영향이 관찰된 경우 현장 사실과 기술 확인 항목을 정리해 적절한 후속 검토의 입력을 만든다.

## 적용 범위

설비 이상 또는 고장 의심 상황에 적용한다. 고장 원인 확정, 수리 승인, 부품 구매와 생산계획 변경은 별도 권한과 절차에 따른다.

## Stakeholder

| 역할 | 책임 |
| --- | --- |
| 현장 작업자 | 대상, 현상, 시점, 운영 영향과 즉시 조치를 기록한다. |
| 설비팀 | 기술적 영향, 제약과 필요한 추가 확인을 검토한다. |
| EHS·제조기획팀 | 안전 또는 생산계획 영향이 있는 경우 각 전문 범위를 검토한다. |

## 프로세스

1. 설비 식별자, 위치, 관찰 시점과 현상을 기록한다.
2. 안전상 즉시 공유가 필요한 사실과 임시 조치를 구분한다.
3. 설비팀이 기술 영향, 제약과 확인 질문을 검토한다.
4. 수리·부품 필요성이 검토되면 기술 근거를 구매 검토의 입력으로 인계한다.
5. 생산·안전 영향과 미확정 항목을 관련 부서에 공유한다.

## 단계별 인계 기준

1. **현장 작업자 → 설비팀:** 설비·위치 식별, 이상 현상·발생 시각·운전 조건, 계기값·사진 등 근거, 즉시 조치와 안전 영향을 전달한다.
2. **설비팀 → 제조기획팀 또는 EHS:** 생산량·일정 영향 또는 안전·환경 영향이 확인된 경우에만, 기술 제약·예상 영향 기간·가동 조건·미확정 원인을 함께 인계한다.
3. **설비팀 → 구매팀:** 교체 부품·외주 정비가 필요하다는 기술 검토가 끝난 뒤, 부품 사양·호환성·필요 시점·대체 가능성·기술 근거를 별도 구매 검토 입력으로 전달한다.
4. **설비팀 → 권한 있는 사람:** 수리·가동 중지·구매 실행은 누적 근거를 바탕으로 별도 승인 절차에서 결정한다.

## 확인 사항과 산출물

- 확인 사항: 설비 식별, 현상, 시점, 운전·안전 영향, 임시 조치, 기술 제약
- 산출물: 이슈 기록, 기술 검토 결과, 추가 확인 목록

## 실행 경계

이 검토는 원인 진단 완료, 수리 승인, 구매 실행 또는 생산 중단 결정을 의미하지 않는다.
