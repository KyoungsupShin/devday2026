# 예방정비 계획·실적 검토

## 목적

계획된 예방정비의 완료 상태와 미완료 사유를 확인하고 운영·생산계획에 영향을 줄 수 있는 제약을 공유한다.

## 적용 범위

주간 또는 월간 예방정비 계획과 실적 기록에 적용한다. 정비 작업 승인과 자재 구매는 별도 절차에 따른다.

## Stakeholder

| 역할 | 책임 |
| --- | --- |
| 설비팀 | 계획 대상, 완료 근거, 미완료 사유와 기술 제약을 검토한다. |
| 현장 작업자 | 현장 운전 조건과 관찰된 제약을 제공한다. |
| 제조기획팀 | 생산계획 또는 투입에 영향이 있을 때 이를 검토한다. |

## 프로세스

1. 기간별 예방정비 계획 대상과 기준 시점을 확인한다.
2. 완료 기록, 작업 근거와 대상 식별 정보를 대조한다.
3. 미완료, 지연, 기술 제약과 추가 확인 사항을 분류한다.
4. 생산·운영 영향이 있는 항목을 제조기획팀과 관련 현장에 공유한다.
5. 구매 또는 승인 필요 여부는 검토 결과와 분리해 기록한다.

## 단계별 인계 기준

1. **현장 작업자 → 설비팀:** 설비 식별자, 계획 작업 창, 실제 운전 제약, 현장 접근·정지 가능 시간과 관찰된 이상을 전달한다.
2. **설비팀 → 제조기획팀:** 미완료·지연 또는 정비 창 변경이 생산에 영향을 줄 때만, 대상 설비·영향 기간·필요 정지 시간·대안 가능 여부·미확정 사항을 인계한다.
3. **설비팀 → 구매팀 또는 권한자:** 부품·외주·승인이 필요하다는 기술 근거가 확보된 경우에만 별도 구매·승인 요청의 입력으로 전달한다. 예방정비 검토 자체는 구매나 작업 실행을 지시하지 않는다.

## 확인 사항과 산출물

- 확인 사항: 계획 대상, 완료 근거, 미완료 사유, 현장 제약, 생산 영향
- 산출물: 정비 검토 기록, 미완료 항목, 영향 공유 기록

## 실행 경계

완료 기록의 검토는 정비 품질 보증, 구매 실행 또는 생산계획 승인으로 해석하지 않는다.
