# 환율·원자재 가격 변동 사업성 평가

## 목적

환율·원자재 가격 변동이 특정 제품 또는 기간의 원가·수익성·사업계획 가정에 미치는 영향을 시나리오로 검토하고, 근거와 불확실성을 분리한다.

## 적용 범위

환율·원자재 가격 변동에 대한 월간 또는 분기 사업성 평가에 적용한다. 예산 배정·승인, 가격 결정, 회계 전기 또는 지급 결정은 포함하지 않는다.

## Stakeholder

| 역할 | 책임 |
| --- | --- |
| 요청 부서 | 평가 대상 제품·기간, 확인하려는 변동 요인과 제공 가능한 계획 근거를 전달한다. |
| 재무팀 | 환율·원자재 가격·제조원가 가정, 비용 근거와 한계를 검토한다. |
| 사업기획팀 | 재무팀 근거를 바탕으로 수요·매출·수익성 시나리오와 계획 가정의 영향을 검토한다. |
| 제조기획팀 | 생산계획·BOM·운영 제약이 실제 판단에 필요한 경우에만 근거를 제공한다. |
| 권한 있는 사람 | 예산·가격·투자 또는 공식 계획 변경이 필요한 경우 최종 결정한다. |

## 프로세스

1. 요청 부서는 평가 대상 제품, 기간, 환율·원자재 가격 변동 요인과 확인하려는 사업성 질문을 재무팀에 전달한다.
2. 재무팀은 제공된 환율·원자재 가격·BOM·제조원가 가정의 시점과 범위를 검토하고, 계산 가능한 시나리오와 누락 입력을 구분한다.
3. 사업기획팀은 재무팀 시나리오를 바탕으로 수요·매출·수익성 및 계획 가정의 영향을 검토한다.
4. 생산계획·BOM 또는 운영 제약이 평가 결과를 바꿀 수 있는 경우에만 제조기획팀에 구체적인 근거와 질문을 인계한다.
5. 재무·사업기획 검토 근거, 시나리오별 불확실성과 추가 입력을 요청 부서에 전달하고, 예산·가격·계획의 공식 결정이 필요하면 권한 있는 사람에게 인계한다.

## 단계별 인계 기준

1. **요청 부서 → 재무팀:** 대상 제품·기간, 환율·원자재 가격 변동 요인, 기존 원가 가정·출처와 확인 질문을 전달한다.
2. **재무팀 → 사업기획팀:** 계산 가능한 원가 시나리오, 가정의 기준일·범위, 누락 입력과 불확실성을 전달해 수요·매출·수익성 영향을 검토하게 한다.
3. **사업기획팀 → 제조기획팀:** 생산계획·BOM·운영 제약이 결과를 바꿀 때만 시나리오와 필요한 확인 항목을 인계한다.
4. **각 검토 부서 → 권한 있는 사람:** 예산·가격·공식 계획 변경은 분석 결과와 분리하여 누적 근거와 함께 별도 결정으로 인계한다.

## 확인 사항과 산출물

- 확인 사항: 제품·기간, 환율·원자재 가격 가정, BOM·제조원가 근거, 수요·매출 가정, 시나리오별 영향, 불확실성
- 산출물: 재무 시나리오 검토 기록, 사업성 영향 요약, 추가 입력 요청, 최종 확인 입력

## 실행 경계

사업성 평가는 확정 손익, 예산 승인, 가격 결정, 자금 배정 또는 회계 처리 완료를 뜻하지 않는다.
