# 사업계획 가정 검토

## 목적

수요·수익·원가·운영 가정의 유효성과 변경 사항을 확인해 사업계획의 불확실성과 영향을 관리한다.

## 적용 범위

월간 또는 분기 사업계획 가정 검토에 적용한다. 확정 실적 보고, 예산 승인과 투자 결정은 별도 절차에 따른다.

## Stakeholder

| 역할 | 책임 |
| --- | --- |
| 사업기획팀 | 계획 가정, 시나리오, 불확실성과 운영 영향을 검토한다. |
| 재무팀 | 원가·예산·비용 통제 관점의 근거를 별도로 제공한다. |
| 제조기획팀 | 생산계획·자재·운영 제약과의 연결 근거를 제공한다. |

## 프로세스

1. 검토 대상 계획, 기간과 주요 가정 목록을 확인한다.
2. 제공된 최신 근거와 기존 가정을 비교한다.
3. 변경, 불확실성 및 추가 확인 필요 사항을 분류한다.
4. 재무·제조기획 영향이 있으면 근거와 질문을 인계한다.
5. 가정 변경과 검토 한계를 기록한다.

## 단계별 인계 기준

1. **요청 부서 → 사업기획팀:** 대상 계획·기간, 변경하려는 수요·가격·물량 등 가정, 근거 출처·기준일과 확인 질문을 전달한다.
2. **사업기획팀 → 재무팀:** 원가·예산·비용 가정이 시나리오에 영향을 주는 경우에만 대상 제품·기간·계산 전제·확인 질문을 인계한다.
3. **사업기획팀 → 제조기획팀:** 생산능력·자재·라인 제약이 가정의 실현 가능성을 바꿀 수 있을 때만 관련 계획과 필요 시점을 인계한다.
4. **사업기획팀 → 권한 있는 사람:** 확정 예산·투자·가격 또는 공식 계획 변경이 필요하면 시나리오, 불확실성 및 전문 검토 결과를 누적해 전달한다.

## 확인 사항과 산출물

- 확인 사항: 계획 기간, 수요·수익·원가 가정, 근거 시점, 변경, 불확실성, 운영 영향
- 산출물: 가정 검토 기록, 시나리오 변경 목록

## 실행 경계

계획 가정 검토는 확정 실적, 예산 승인 또는 사업 의사결정을 자동으로 확정하지 않는다.
