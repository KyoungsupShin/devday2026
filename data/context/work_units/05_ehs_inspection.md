# 안전·환경 점검

## 목적

작업 안전, 환경 관리, 화학물질과 작업허가 관련 기록을 검토해 조치가 필요한 위험과 확인 항목을 관리한다.

## 적용 범위

일일·주간 또는 규정상 필요한 안전·환경 점검에 적용한다. 현장 작업의 공식 허가 또는 법적 판정은 별도 권한 절차에 따른다.

## Stakeholder

| 역할 | 책임 |
| --- | --- |
| EHS | 안전·환경 증빙, 미흡 사항과 필요한 후속 확인을 검토한다. |
| 현장 작업자 | 현장 상태, 관찰 사실과 즉시 조치를 기록한다. |
| 설비·생산팀 | 설비·운영 영향이 있는 항목에 대한 사실과 근거를 제공한다. |

## 프로세스

1. 점검 대상, 시점, 적용 작업과 필요한 증빙을 확인한다.
2. 안전·환경·화학물질·작업허가 관련 기록을 검토한다.
3. 미흡 사항과 즉시 공유가 필요한 위험을 구분한다.
4. 필요한 부서에 영향과 확인 질문을 인계한다.
5. 조치 확인 일정, 담당자와 미확정 항목을 기록한다.

## 단계별 인계 기준

1. **현장 작업자 → EHS:** 대상 작업·위치·시점, 적용 허가·보호구·화학물질 정보, 관찰 사실, 사진 등 증빙과 즉시 조치를 전달한다.
2. **EHS → 설비·생산팀:** 설비 상태나 운전 조건이 위험과 직접 연결된 경우에만, 위험 설명·영향 범위·확인 질문·요구 증빙을 인계한다.
3. **EHS → 권한 있는 절차:** 작업 중지, 허가 발급, 법적 신고 또는 공식 시정조치가 필요한 상태는 근거와 함께 권한자에게 전달한다. 점검 결과만으로 해당 조치를 실행하지 않는다.

## 확인 사항과 산출물

- 확인 사항: 점검 대상, 증빙, 위험 사실, 즉시 조치, 영향 부서, 후속 기한
- 산출물: EHS 점검 기록, 조치 추적 목록

## 실행 경계

점검 결과는 허가 발급, 작업 승인 또는 사고 원인 확정을 자동으로 수행하지 않는다.
