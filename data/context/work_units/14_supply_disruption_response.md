# 수급 위험 또는 공급 차질 대응

## 목적

재고 부족, 입고 지연 또는 공급 조건 변경이 확인된 경우 수급 근거와 생산계획 영향을 분리해 대응 검토의 입력을 만든다.

## 적용 범위

수급 위험 또는 공급 차질이 발생한 관리 품목에 적용한다. 대체 품목 승인, 공급처 변경, 구매 실행과 생산계획 확정은 별도 절차에 따른다.

## Stakeholder

| 역할 | 책임 |
| --- | --- |
| 구매팀 | 품목, 재고, 수요, 입고와 공급 조건의 근거를 검토한다. |
| 제조기획팀 | 생산계획·투입 준비도에 미치는 영향을 검토한다. |
| 설비·품질팀 | 부품 기술 적합성 또는 품질 영향 검토가 필요한 경우 각 근거를 제공한다. |

## 프로세스

1. 위험 품목, 요구 시점과 발생 조건을 확인한다.
2. 재고, 수요, 입고와 공급 조건의 기록을 검토한다.
3. 부족·지연·조건 변경과 미확정 정보를 구분한다.
4. 대체 가능성 또는 생산계획 영향이 필요한 경우 관련 부서에 근거를 인계한다.
5. 확인 결과, 제약, 담당자와 다음 확인 기한을 기록한다.

## 단계별 인계 기준

1. **요청 부서 또는 현장 → 구매팀:** 품목·사양·필요 수량·시점, 공급 차질 사실, 재고·수요 근거와 운영 영향을 전달한다.
2. **구매팀 → 제조기획팀:** 재고·예약·입고·공급 조건과 부족 예상 시점을 바탕으로, 생산계획·투입 준비도 영향 검토를 인계한다.
3. **구매팀 또는 제조기획팀 → 설비·품질팀:** 대체품의 기술 적합성 또는 품질 영향이 실제 쟁점일 때만 대체 후보·규격·필요 시점·확인 질문을 전달한다.
4. **구매팀 → 권한 있는 사람:** 공급처 변경·대체 승인·구매 실행이 필요한 경우 누적 근거, 위험 및 미확정 항목을 별도 결정으로 인계한다.

## 확인 사항과 산출물

- 확인 사항: 품목, 기준 시점, 수요, 재고, 입고, 공급 조건, 생산 영향
- 산출물: 수급 위험 기록, 영향 검토 결과, 추가 확인 목록

## 실행 경계

대응 검토는 공급처 변경, 대체 자재 승인, 구매 실행 또는 생산계획 변경을 결정하지 않는다.
