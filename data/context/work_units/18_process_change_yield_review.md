# 공정 변경 또는 수율 저하 검토

## 목적

공정 조건 변경, 수율·처리량 저하가 확인된 경우 공정·생산 기록과 관련 전문 부서의 근거를 연결해 추가 검증 필요 사항을 정리한다.

## 적용 범위

공정 변경 또는 수율·처리량 저하 검토에 적용한다. 공정 변경 승인, 생산 release, 설비 수리와 품질 판정은 별도 절차에 따른다.

## Stakeholder

| 역할 | 책임 |
| --- | --- |
| 공정팀 | 공정 조건, 제약, 수율·처리량 관련 기록을 검토한다. |
| 생산팀 | 라인 운영, 실행 기록과 현장 영향을 제공한다. |
| 설비·품질·R&D팀 | 연결 근거가 있을 때 기술·품질·개발 관점의 확인을 제공한다. |

## 프로세스

1. 현상, 기간, 대상 제품·라인·공정 조건을 확인한다.
2. 공정·생산 기록과 수율·처리량 근거를 검토한다.
3. 설비·품질·R&D와 연결되는 확인된 근거와 미확정 가설을 구분한다.
4. 필요한 전문 부서에 추가 검증 질문을 인계한다.
5. 영향, 제약, 추가 검증과 공식 승인 필요 여부를 기록한다.

## 단계별 인계 기준

1. **생산팀 → 공정팀:** 제품·라인·기간, 변경된 조건 또는 수율·처리량 현상, 생산·설비 기록, 기준선과 관찰 사실을 전달한다.
2. **공정팀 → 설비·품질·R&D팀:** 기술·설비, 규격·품질 또는 배합·개발 요인이 검증에 필요한 경우에만 각각의 근거·가설·질문을 인계한다.
3. **공정팀 → 권한 있는 사람:** 검증 결과, 영향 범위, 남은 불확실성과 변경 전제조건을 누적해 공정 변경 승인 또는 별도 실행 절차의 입력으로 전달한다.

## 확인 사항과 산출물

- 확인 사항: 기간, 대상, 공정 조건, 수율·처리량, 생산 기록, 관련 영향, 검증 질문
- 산출물: 공정 영향 검토 기록, 추가 검증 요청

## 실행 경계

검토 결과는 공정 변경 구현, 설비 원인 확정, 품질 release 또는 생산 실행 승인을 뜻하지 않는다.
