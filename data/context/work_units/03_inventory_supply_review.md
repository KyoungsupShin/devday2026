# 기존 원부자재 추가 발주·수급 검토

## 목적

기존 원부자재의 추가 발주 필요에 대해 재고, 수요, 입고와 공급 조건을 확인하고 생산계획 영향과 공식 요청에 필요한 근거를 누적한다.

## 적용 범위

기존 등록 원부자재의 추가 발주 요청과 주간 수급 검토에 적용한다. 신규 자재 등록, 공급처 선정, 계약 체결, 구매 승인과 발주는 포함하지 않는다.

## Stakeholder

| 역할 | 책임 |
| --- | --- |
| 요청 부서 | 품목, 추가 발주 사유, 필요 시점과 제공 가능한 수요 근거를 전달한다. |
| 구매팀 | 재고·수요·입고·공급 조건과 구매 요청 상태의 근거와 한계를 검토한다. |
| 제조기획팀 | 구매팀 근거를 바탕으로 생산계획과 투입 준비도에 미치는 영향을 검토한다. |
| 권한 있는 사람 | 누적 근거를 바탕으로 공식 구매 요청 제출·승인 여부를 최종 결정한다. |

## 프로세스

1. 요청 부서는 기존 등록 품목, 추가 발주 사유, 필요 시점, 수량·수요 근거와 미확정 항목을 구매팀에 전달한다.
2. 구매팀은 기준정보, 재고·예약·수요, 입고 계획, 공급 조건과 기존 구매 요청 상태를 검토하고 부족·지연·확인 불가 항목을 구분한다.
3. 제조기획팀은 구매팀 검토 근거를 바탕으로 생산계획, 투입 준비도와 운영 영향 및 필요한 시점을 검토한다.
4. 설비 제약, 품질·규격 또는 안전 영향이 실제로 확인된 경우에만 해당 책임 부서에 근거와 질문을 인계한다. 이 항목은 추가 발주의 기본 필수 단계가 아니다.
5. 구매팀·제조기획팀의 근거와 미확정 항목을 누적해 요청 부서에 전달하고, 공식 구매 요청 제출·승인이 필요하면 권한 있는 사람에게 최종 확인을 인계한다.

## 단계별 인계 기준

1. **요청 부서 → 구매팀:** 기존 품목·수량·필요 시점, 추가 발주 사유, 수요 근거와 미확정 항목을 전달한다.
2. **구매팀 → 제조기획팀:** 기준정보, 재고·예약·입고·공급 조건과 부족·지연 위험을 근거로 생산 영향 검토를 인계한다.
3. **구매팀·제조기획팀 → 권한 있는 사람:** 누적 검토와 미확정 사항을 전달하되, 구매 요청 제출·승인·발주는 별도 공식 결정으로 구분한다.

## 확인 사항과 산출물

- 확인 사항: 품목 식별, 추가 발주 사유, 수요·수량 근거, 재고 시점, 입고 계획, 공급 조건, 생산 영향, 위험·미확정 항목
- 산출물: 구매팀 수급 검토 기록, 제조기획 영향 검토 기록, 누적 인계서, 최종 확인 요청

## 실행 경계

수급 검토 순서는 근거 축적 기준이며 구매 실행, 공급처 확정, 계약 체결, 구매 승인 또는 발주를 뜻하지 않는다.
