# 품질 이탈 또는 규격 미확정 검토

## 목적

시험·검사 결과 이탈 또는 규격 관련 미확정 사항이 발생했을 때 확인 범위와 필요한 전문 검토를 정리한다.

## 적용 범위

품질 이탈, 시험·검사 결과 이상 또는 규격 미확정 이슈에 적용한다. 제품 처분, 품질 release와 출하 승인 결정은 포함하지 않는다.

## Stakeholder

| 역할 | 책임 |
| --- | --- |
| 품질팀 | 기록, 규격, 확인 범위와 공식 판정 필요 사항을 검토한다. |
| 생산팀 | 배치·라인·생산 실행 관련 기록과 영향을 제공한다. |
| R&D·공정팀 | 개발·규격 또는 공정 조건 관련 추가 근거를 제공한다. |

## 프로세스

1. 대상, 기록, 적용 규격과 이탈 또는 미확정 사실을 확인한다.
2. 확인된 결과와 데이터·규격의 미확정 항목을 구분한다.
3. 생산·R&D·공정 영향이 필요한 경우 해당 부서에 근거와 질문을 인계한다.
4. 추가 시험·검사 또는 확인에 필요한 입력을 기록한다.
5. 공식 판정·승인이 필요한 상태를 별도로 표시한다.

## 단계별 인계 기준

1. **생산팀 → 품질팀:** 배치·제품·라인, 적용 규격, 이탈 수치·시험 기록, 발생 시점·공정 조건과 즉시 격리·보존 등 사실을 전달한다.
2. **품질팀 → R&D·공정팀:** 규격·시험법·배합·공정 조건의 추가 해석이 필요한 경우에만, 확인된 이탈과 미확정 가설을 구분해 질문을 인계한다.
3. **품질팀 → 권한 있는 사람:** 추가 시험과 전문 검토가 누적된 후 처분·release·출하 등 공식 판정에 필요한 근거와 미확정 사항을 전달한다.

## 확인 사항과 산출물

- 확인 사항: 대상 식별, 규격, 시험 기록, 이탈 사실, 영향 범위, 추가 확인
- 산출물: 품질 이슈 검토 기록, 추가 검토 요청

## 실행 경계

품질 이슈 검토는 품질 판정, 제품 처분, release 또는 출하 승인을 대신하지 않는다.
