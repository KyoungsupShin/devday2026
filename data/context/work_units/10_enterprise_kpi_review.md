# 전사 KPI 검토

## 목적

전사 및 팀별 KPI의 데이터 품질, 추세, 이탈 원인과 조치 상태를 검토해 운영 상태를 공통 기준으로 관리한다.

## 적용 범위

월간 또는 분기 KPI 리뷰에 적용한다. KPI만으로 개인·조직의 성과, 예산 승인 또는 업무 실행을 자동 결정하지 않는다.

## Stakeholder

| 역할 | 책임 |
| --- | --- |
| 경영·운영 책임자 | KPI 정의, 이탈 근거와 조치 상태를 검토한다. |
| 각 지표 주관 부서 | 데이터 출처, 산식, 제한 사항과 조치 근거를 제공한다. |
| 재무·사업기획팀 | 비용·계획 관련 지표의 전문 근거를 각 범위에서 제공한다. |

## 프로세스

1. KPI 정의, 산식, 기간과 기준값의 적용 여부를 확인한다.
2. 데이터 출처, 시점, 누락·중복과 집계 제한을 검증한다.
3. 추세와 이탈을 관찰하고 원인으로 확인된 사실과 미확정 가설을 구분한다.
4. 조치가 필요한 항목의 담당 부서, 기한과 완료 기준을 기록한다.
5. 권한 있는 결정이 필요한 경우 누적 근거를 별도 절차로 인계한다.

## 단계별 인계 기준

1. **지표 주관 부서 → 경영·운영 책임자:** KPI 정의·산식·대상 기간, 데이터 출처·기준일, 누락·중복 제한, 추세와 조치 현황을 전달한다.
2. **경영·운영 책임자 → 재무·사업기획팀:** 비용·수익성·계획 가정의 전문 검토가 이탈 해석에 필요한 경우에만 해당 KPI와 질문·근거를 인계한다.
3. **경영·운영 책임자 → 담당 부서·권한자:** 이탈에 대한 조치 과제는 담당자·기한·완료 기준을 명시해 전달하며, 예산·조직·시스템 변경 결정은 KPI 검토와 분리한다.

## 확인 사항과 산출물

- 확인 사항: KPI 정의, 기간, 산식, 데이터 품질, 추세, 이탈, 조치 상태
- 산출물: KPI 리뷰 기록, 조치 계획

## 실행 경계

KPI 리뷰는 승인·예산 배정·인사 평가 또는 시스템 변경을 자동으로 수행하지 않는다.
