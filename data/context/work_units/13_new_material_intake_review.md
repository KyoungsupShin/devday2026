# 신규 원부자재 생산 투입 검토

## 목적

신규 원료·부자재의 생산 투입을 검토할 때 계획, 자재 기준정보, 투입 준비도와 운영 영향을 명확히 한다.

## 적용 범위

신규 원부자재의 생산 투입 검토에 적용한다. 품질 release, 제품 승인, 생산 실행과 ERP 반영은 별도 절차에 따른다.

## Stakeholder

| 역할 | 책임 |
| --- | --- |
| 요청 부서 | 신규 자재, 적용 제품·라인, 목표 투입 시점과 요청 목적을 전달한다. |
| 제조기획팀 | 계획 범위, 자재·투입 준비도와 운영 제약을 최초로 검토한다. |
| 구매팀 | 제조기획팀이 확인한 대상 범위를 바탕으로 자재 기준정보·수급·공급 관련 근거를 검토한다. |
| R&D·품질팀 | 신규 규격·배합·품질 확인이 실제로 필요한 경우 각 범위를 검토한다. |
| 생산팀 | 생산 실행·라인 준비 관련 확인이 실제로 필요한 경우 근거를 제공한다. |
| 권한 있는 사람 | 공식 자재 등록, 품질 release, 생산 투입 또는 시스템 변경이 필요한 경우 최종 결정한다. |

## 프로세스

1. 요청 부서는 신규 자재, 적용 제품·라인, 계획 기간, 목표 투입 시점과 미확정 사항을 제조기획팀에 전달한다.
2. 제조기획팀은 적용 범위, BOM·계획 연계, 자재·투입 준비도와 운영 제약을 검토한다.
3. 구매팀은 제조기획팀 근거를 바탕으로 자재 기준정보, 수급·공급 조건과 등록 준비 상태를 검토한다.
4. 신규 규격·배합·품질 확인 또는 생산 실행 영향이 실제로 확인된 경우에만 R&D·품질팀·생산팀에 각 근거와 질문을 인계한다. 이 전문 검토는 대상별 필요 조건이며 모든 신규 자재에 자동으로 추가하지 않는다.
5. 누적 근거, 제약, 미확정 항목과 공식 등록·release·투입·시스템 변경이 필요한 최종 지점을 요청 부서와 권한 있는 사람에게 전달한다.

## 단계별 인계 기준

1. **요청 부서 → 제조기획팀:** 신규 자재·적용 제품·라인·목표 투입 시점, 계획 기간 및 미확정 사항을 전달한다.
2. **제조기획팀 → 구매팀:** BOM·계획 연계, 자재 준비도와 운영 제약을 근거로 기준정보·수급·등록 준비도 검토를 인계한다.
3. **제조기획팀·구매팀 → R&D·품질·생산팀:** 신규 규격·배합·품질·생산 실행 영향이 실제로 확인된 경우에만 대상별 근거와 질문을 전달한다.
4. **누적 검토 → 권한 있는 사람:** 공식 등록·품질 release·생산 투입·ERP 변경 필요 여부는 누적 근거 및 미확정 항목과 함께 별도 최종 결정으로 인계한다.

## 확인 사항과 산출물

- 확인 사항: 자재 식별, 적용 제품·라인, BOM, 계획 기간, 수급, 등록 준비, 규격·개발·품질·생산 영향, 미확정 항목
- 산출물: 제조기획·구매 검토 기록, 조건부 전문 검토 요청, 누적 인계서, 최종 확인 입력

## 실행 경계

준비도 검토는 신규 자재의 품질 승인, 생산 투입 승인 또는 시스템 변경을 뜻하지 않는다.
