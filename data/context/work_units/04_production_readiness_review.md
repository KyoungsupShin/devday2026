# 생산계획·투입 준비도 검토

## 목적

생산계획, 자재·투입 준비도와 라인 운영 제약을 확인해 생산 투입 전 필요한 검토를 정리한다.

## 적용 범위

주간 생산계획과 투입 준비도 검토에 적용한다. 생산 실행 지시, 품질 release와 예산 결정은 포함하지 않는다.

## Stakeholder

| 역할 | 책임 |
| --- | --- |
| 제조기획팀 | 계획 범위, 투입 준비도와 운영 제약을 검토한다. |
| 구매팀 | 자재 기준정보·재고·수급 관련 근거를 제공한다. |
| 설비·품질팀 | 설비 제약 또는 품질·규격 확인이 필요한 항목을 각 범위에서 검토한다. |

## 프로세스

1. 계획 대상, 기간, 라인과 투입 범위를 확인한다.
2. 자재·BOM·투입 준비 근거와 생산계획을 검토한다.
3. 설비, 구매, 품질 관련 영향과 미확정 항목을 구분한다.
4. 각 전문 부서에 필요한 질문과 근거를 인계한다.
5. 준비도, 제약, 확인 주체와 다음 검토를 기록한다.

## 단계별 인계 기준

1. **제조기획팀 → 구매팀:** 계획 품목·라인·기간, 필요 수량·투입 시점, BOM 기준과 자재 준비도 질문을 전달한다. 구매팀은 재고·예약·입고·공급 조건과 확인 불가 항목을 회신한다.
2. **제조기획팀 → 설비팀:** 설비 가용성·정비 창·기술 제약이 준비도를 좌우하는 경우에만 대상 설비, 필요한 가동 조건과 계획 영향을 인계한다.
3. **제조기획팀 → 품질팀:** 신규 규격, 시험·검사 상태 또는 품질 확인이 실제 투입 조건인 경우에만 관련 자재·제품·배치·규격과 질문을 전달한다.
4. **제조기획팀 → 권한 있는 사람:** 각 검토 결과를 누적하되, 생산 지시·품질 release·계획 변경의 공식 결정은 별도로 인계한다.

## 확인 사항과 산출물

- 확인 사항: 계획 기간, 품목·라인, 자재 준비, 설비 제약, 품질 확인, 운영 영향
- 산출물: 준비도 검토 기록, 제약 목록, 추가 검토 요청

## 실행 경계

준비도 검토는 생산 승인, 품질 판정 또는 실제 생산 실행을 뜻하지 않는다.
