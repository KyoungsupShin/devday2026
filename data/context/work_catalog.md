# 전사 운영 업무 카탈로그와 KPI 기준

## 목적과 적용 범위

이 문서는 부서 간 협업 SOP와 역할·책임 운영기준을 보완하기 위해 전사 KPI, 팀별 KPI, 정기 업무와 비정기 업무의 관리 기준을 정리한다. 업무별 절차는 필요한 검토 순서와 산출물을 설명하며, 승인·구매 실행·예산 배정·ERP 변경 또는 외부 발송 권한을 부여하지 않는다.

목표값, 허용 범위, 평가 등급, 예산 한도와 조직별 책임자는 최신 사업계획·운영 규정·권한 체계에 따라 별도로 정한다. 이 문서의 KPI와 작업 목록만으로 개인 또는 조직의 성과를 자동 판정하지 않는다.

## 공통 업무 운영 원칙

- 업무마다 대상, 기간, 목적, 근거 출처와 담당 부서를 기록한다.
- 제공되지 않은 수치·상태·승인 정보는 추정하지 않고 확인 항목으로 남긴다.
- 결과에는 확인된 사실, 미확정 항목, 다음 조치와 공식 승인 여부를 분리해 기록한다.
- 설비·설비 부품·유지보수 구매 요청은 설비팀 → 구매팀 → 제조기획팀의 검토 근거를 누적한다.
- 업무 현황, 지표, 로컬 스냅샷은 해당 기록 시점과 범위의 근거이며 최신 운영 상태나 실행 완료를 뜻하지 않는다.

## KPI 관리 공통 기준

| 항목 | 정의 | 관리 방식 |
| --- | --- | --- |
| 지표 목적 | 어떤 운영 결과 또는 통제 상태를 관찰하는지 설명한다. | KPI마다 목적을 명시한다. |
| 산식 | 분자, 분모, 단위, 집계 기간과 제외 기준을 정의한다. | 원천 데이터와 계산 기준을 함께 기록한다. |
| 기준값 | 목표, 경보, 허용 범위를 의미한다. | 권한 있는 경영·운영 책임자가 별도로 정한다. |
| 데이터 품질 | 데이터의 시점, 누락, 중복, 변경 이력을 뜻한다. | 집계 전 검증 결과와 제한 사항을 기록한다. |
| 검토 주기 | 일·주·월·분기 등 지표 확인 간격이다. | 업무 성격에 따라 운영 책임자가 정한다. |
| 조치 관리 | 기준 이탈 또는 데이터 이상 시 필요한 확인·개선 활동이다. | 원인, 담당 부서, 완료 기준을 별도 기록한다. |

## 전사 KPI

| KPI | 목적 | 산식 또는 관찰 기준 | 주관 부서 | 설명 |
| --- | --- | --- | --- | --- |
| 안전·환경 준수율 | 안전·환경 관리 활동의 이행 상태를 관찰한다. | 완료된 필수 점검·조치 건수 ÷ 계획 또는 요구된 점검·조치 건수 | EHS | 안전·환경 의무 이행의 누락을 확인한다. 사고 발생 여부만으로 관리하지 않는다. |
| 생산계획 달성률 | 승인된 생산계획과 실제 생산 실행의 차이를 관찰한다. | 기간 내 계획 대비 완료 수량 또는 생산 일정 달성 수준 | 제조기획·생산 | 계획 변경, 품질 hold, 설비 이상 등 차이의 근거를 함께 관리한다. |
| 품질 적합성 지표 | 시험·검사·규격 적합성의 운영 상태를 관찰한다. | 규격 적합 판정 건수 ÷ 시험 또는 검사 완료 건수 | 품질 | 품질 release나 출하 승인 권한을 대신하지 않는다. |
| 공급 연속성 지표 | 필요한 자재와 부품의 수급 위험을 관찰한다. | 요구 시점에 확보된 품목 수 ÷ 관리 대상 품목 수 | 구매·제조기획 | 재고, 입고 계획, 공급 조건의 시점과 범위를 함께 확인한다. |
| 원가·예산 통제 지표 | 예산, 원가 및 비용 귀속의 통제 상태를 관찰한다. | 승인된 기준 대비 집행·예상 비용의 차이 및 확인 완료 상태 | 재무 | 예산 승인이나 배정을 자동으로 판단하지 않는다. |
| 사업계획 건전성 지표 | 수요·수익·원가 가정과 사업성 검토의 최신성을 관찰한다. | 계획 가정의 검토 완료 상태와 주요 가정 변경 내역 | 사업기획 | 확정 실적과 계획·시나리오를 구분한다. |
| 데이터·변경 통제 준수율 | 승인된 변경의 데이터 검증과 추적성 상태를 관찰한다. | 필수 검증·추적 기록이 있는 변경 건수 ÷ 관리 대상 변경 건수 | IT | 실제 시스템 반영 성공률이나 변경 승인과는 별도 지표다. |
| 운영 이슈 해결 리드타임 | 현장 이슈가 등록부터 검토 완료까지 걸리는 시간을 관찰한다. | 이슈 접수 시각부터 정의된 검토 종료 시각까지의 경과 시간 | 설비·운영 책임 부서 | 긴급도, 대기 시간, 외부 의존성을 구분해 해석한다. |

## 팀별 KPI

| 팀 | KPI | 목적과 산식 또는 관찰 기준 | 설명 |
| --- | --- | --- | --- |
| 설비팀 | 설비 검토 리드타임 | 현장 요청 접수부터 기술 검토 결과 전달까지의 경과 시간 | 긴급도와 기술 정보 부족으로 인한 대기 시간을 분리한다. |
| 설비팀 | 예방정비 이행률 | 완료된 예방정비 건수 ÷ 계획된 예방정비 건수 | 단순 완료 여부 외에 기록의 완결성을 함께 점검한다. |
| 구매팀 | 수급 확인 완료율 | 기준정보·재고·수급·공급 조건 확인이 완료된 요청 수 ÷ 검토 요청 수 | 공급처 선정이나 구매 승인과 구분한다. |
| 구매팀 | 구매 요청 검토 리드타임 | 설비 또는 요청 부서의 근거 수령부터 조달 검토 결과 전달까지의 시간 | 미확정 사양으로 인한 대기 사유를 남긴다. |
| 제조기획팀 | 자재·투입 준비도 확인율 | 계획·자재·투입 관련 확인이 완료된 대상 수 ÷ 관리 대상 수 | 생산 승인이나 품질 판정의 지표가 아니다. |
| 제조기획팀 | 계획 변경 반영 적시성 | 확인된 변경이 정의된 계획 검토 주기 내 반영되었는지의 상태 | 변경의 승인 여부와 반영 가능 여부를 분리한다. |
| 재무팀 | 예산·비용 검토 완결성 | 필요한 예산·원가·비용 귀속 근거가 갖춰진 검토 건수 ÷ 검토 건수 | 예산 승인 건수로 해석하지 않는다. |
| 사업기획팀 | 계획 가정 검토 최신성 | 정의된 검토 주기 안에 갱신·검토된 주요 가정의 비율 | 수요·수익·원가 시나리오와 확정 실적을 구분한다. |
| IT팀 | 변경 검증 추적성 완결성 | 필수 식별자·매핑·검증·롤백 기록이 있는 변경 건수 ÷ 관리 대상 변경 건수 | 시스템 변경 실행 또는 승인 결과와 분리한다. |
| EHS | 안전·환경 조치 이행률 | 완료된 안전·환경 조치 건수 ÷ 계획 또는 요구 조치 건수 | 현장·설비·품질의 전문 판단을 대신하지 않는다. |
| 생산팀 | 생산 실행 안정성 | 계획된 작업의 실행 상태, 라인 중단 및 재개 기록의 완결성 | 설비 원인 진단이나 품질 판정은 별도 부서 근거를 따른다. |
| 품질팀 | 시험·검사 기록 완결성 | 필수 시험·검사·규격 확인 기록이 있는 건수 ÷ 대상 건수 | 품질 release의 공식 결정과 분리한다. |

## KPI 이탈과 업무 이슈의 관리 절차

1. 지표 이탈 또는 업무 이슈를 발견한 부서는 대상, 기간, 관찰 사실과 데이터 출처를 기록한다.
2. 데이터 누락·중복·시점 차이와 실제 운영 이슈를 구분해 확인한다.
3. 원인과 영향이 다른 부서의 전문 검토를 필요로 하면 R&R 문서의 인계 형식에 따라 요청한다.
4. 조치가 필요한 경우 담당 부서, 확인 기한, 완료 기준과 미확정 항목을 기록한다.
5. 예산 배정, 구매 실행, 공식 승인, 외부 발송 또는 시스템 쓰기가 필요하면 누적 근거를 권한 있는 사람에게 전달한다.

## 데이터와 실행 경계

이 문서의 KPI와 업무 목록은 운영 현황을 공통 언어로 정리하기 위한 기준이다. 문서에 제시된 절차와 지표만으로 업무를 자동 실행하거나 성과·승인·예산·구매·시스템 변경을 확정할 수 없다. 실제 실행은 각 조직의 최신 권한 체계, 운영 규정과 공식 절차에 따른다.
